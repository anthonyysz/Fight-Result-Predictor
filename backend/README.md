# Backend

The back end gives us all of the functions we need to properly run everything. Running scrapers, making predictions and loading data to the database keeps everything organized and running smoothly.

## 1. Layout

- `src/historical_scraper/`
  - Scrapes past UFC events, starting at a certain date through present day
- `src/upcoming_scraper/`
  - Scrapes the next upcoming event only
- `src/model_training/`
  - Retrains the models and saves the new ones, reusing code from notebook 3
- `src/api/`
  - Runs the local FastAPI admin API for scraping, loading data, predictions, stats charts, and reports
- `src/reports/`
  - Generates local fight-week CSV, HTML, and text report files
- `data/reference/`
  - Source files the scraper reads, such as `fighter_aliases.csv` and `rankings_history.csv`
- `data/generated/`
  - CSV, report, log, and chart outputs generated by local commands
- `db/`
  - PostgreSQL schema and test queries
- `.env`
  - Backend environment variables and database connection settings

## 2. Install

From the repo root:

```powershell
.venv\Scripts\python -m pip install -e .\backend
```
## 3. Load the back end

From the backend directory, set `PYTHONPATH`:
```powershell
$env:PYTHONPATH = (Resolve-Path .\src).Path
```

Start or reload the API:
```powershell
& "..\.venv\Scripts\python.exe" -m uvicorn api.app:app --host 127.0.0.1 --port 8000 --reload
```

Check that it is live:
```powershell
Invoke-WebRequest -Uri http://127.0.0.1:8000/health -UseBasicParsing
```

## 4. Database testing

To get to the database from powershell:
```powershell
psql $env:DATABASE_URL
```

The `psql` commands need `DATABASE_URL` set in the current PowerShell session. The backend can read `backend/.env`, but `psql` will not read that file automatically.

```powershell
psql $env:DATABASE_URL -c "SELECT fight_date, red_fighter, blue_fighter, weight_class, source_name FROM public.all_fights ORDER BY fight_date DESC LIMIT 20;"
```

## 5. Running Programs

From the repo root unless a command says otherwise.

Retrain models:
```powershell
.venv\Scripts\python -m model_training.retrain_models
```
Retraining saves model bundles locally under `models/`.

Use historical scraper:
```powershell
.venv\Scripts\python -m historical_scraper.main --start-date <day-after-latest-all-fights-date>
```

Use upcoming scraper:
```powershell
.venv\Scripts\python -m upcoming_scraper.main
```

Publish static frontend stats charts:
```powershell
.venv\Scripts\python -m maintenance.publish_static_assets
```

The API commands below require the backend from section 3 to be running.

Scrape recent historical fights through the API:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/recent-fights/scrape' -ContentType 'application/json' -Body '{}'
```

Scrape upcoming fights through the API:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/upcoming-fights/scrape'
```

## 6. Loading data to Postgres

Load historical scraped data:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/fights/load' -ContentType 'application/json' -Body '{"source":"recent"}'
```

Load from testing.csv:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/fights/load' -ContentType 'application/json' -Body '{"source":"testing"}'
```

Load upcoming fights:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/fights/load' -ContentType 'application/json' -Body '{"source":"upcoming_fights"}'
```

Load upcoming metadata:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/fights/load' -ContentType 'application/json' -Body '{"source":"upcoming_metadata"}'
```

## 7. Generate predictions and complete finished fights

Generate upcoming predictions from Postgres using local model files:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/upcoming-predictions/generate'
```

Complete fights after they are done:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/upcoming-fights/finish'
```

## 8. Local fight week report

From the repo root, generate a fight-week report without starting the FastAPI backend:
```powershell
.\scripts\generate-fight-report-now.ps1
```

The command scrapes the nearest event for the current week, loads the generated CSVs into Postgres, generates predictions, and writes the latest CSV/HTML/text report files under `backend/data/generated/reports`.

You can also generate the report through the local API:
```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/admin/fight-week-report' -ContentType 'application/json' -Body '{}'
```

Generate a report for a specific week:
```powershell
.\scripts\generate-fight-report-now.ps1 -ReferenceDate 2026-07-11
```
